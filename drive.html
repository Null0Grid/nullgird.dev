> self-hosted file sync v5.1.0

NULL//DRIVE

File sync like Dropbox, on a server you run.

Run the Null Drive server on a NAS, mini PC or VPS, then install the desktop app on each computer. Your files sync through hardware you own.

Download

What's inside

One server binary with the web app built in, plus a desktop app for Windows and Linux.

Delta sync

Files are split into content-defined chunks, so a 1 MiB edit to a 1 GiB file sends about 4.5 MiB.

Version history

Roll any file back to an earlier version. Deleted files wait in a Recently deleted bin.

No lost edits

When two computers change the same file, you keep both copies.

Locked down

Optional end-to-end encryption per account, two-factor login, lockout after failed attempts and an audit log.

Easy pairing

The desktop app finds your server on the local network, or pairs with a short code.

Web app built in

Browse, upload and download from any browser at your server's address.

Works with the suite

Drive is where the rest of the suite keeps your files.

Null Notes

Sync your notes vault to Drive and keep it the same on every computer.

Null Grid

Browse, view and download your Drive files from inside the browser.

Null Search new in 5.0

Your Drive files show up in your own Null Search results. Click one and nulldrive:// opens it from your sync folder.
