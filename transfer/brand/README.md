# Null brand files

Made 2026-10-30 from the brand brief (section 2). Drawn from geometry in `brand.py`, so they match your lockup image closely but not pixel for pixel: check before using them in the apps.

| File | Use |
| --- | --- |
| `mark.svg` | The mark, flat white |
| `mark-black.svg` | The mark, flat black, for light surfaces |
| `mark-thick.svg` | Thicker ring and slashes for 24 px and smaller |
| `mark-glitch.svg` | Mark with the pink/cyan glitch, for hero and share images |
| `wordmark.svg` | NULL with the notched U (hero scale) |
| `wordmark-plain-u.svg` | NULL with the plain U (small sizes) |
| `lockup-standard.svg` / `.png` | Mark + wordmark, flat white on #0a0a0f |
| `lockup-hero.svg` / `.png` | Mark + wordmark + SUITE · SYSTEMS · LABS, glitch, scanlines (1280×720) |
| `favicon.svg` | Thick mark; white in dark browsers, black in light ones |
| `favicon-16/32/48.png` | Thick mark on #0a0a0f |
| `icon-180.png`, `icon-512.png` | Apple touch icon and large app icon |
| `store-tile-300/150/71.png` | Microsoft Store tiles |
| `og-share.png` | Share image: your hero lockup, as supplied |
