Built to work together

Each app stands alone. Run more than one and they connect.

→

Null Grid searches through Null Search. With Vault switched on, your own saved pages merge into the results.

→

Null Grid connects to your Null Drive. Add its address and token in Settings. The browser talks to Drive directly, never through the search server.

→

Null Notes syncs your vault to Null Drive. Two-way sync follows renames and keeps both copies when both sides change. Locked notes upload still encrypted.

→

Notes open from search results. Each result carries a nullnotes:// link that opens the note right in the app.

→ 5.0

New in 5.0: your notes and files in Null Search. Matching notes and Drive files show beside web results. Queries go straight from your browser to your own server, with a token that can only search, and each account sees only its own files.
