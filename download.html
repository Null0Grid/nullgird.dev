Server

One Go binary with the web app built in. Runs anywhere Docker does.

Docker amd64 · arm64

$ docker run -d --name nulldrive -p 8080:8080 \
    -v nulldrive-data:/data --restart unless-stopped \
    ghcr.io/null0grid/null-drive:latest

Then open http://<server>:8080 and finish the setup wizard before exposing the port to the internet. For LAN discovery on Linux, use host networking (see INSTALL.md).

Each archive has nulldrive (the server) and nulldrive-e2ee (the encryption CLI). Run it with a data directory:

$ NULLDRIVE_DATA_DIR=/srv/nulldrive ./nulldrive

Up and syncing in four steps

  1. Run the server

    Paste the Docker command on your NAS, mini PC or VPS.

  2. Open the browser

    Go to :8080 and create your admin account in the setup wizard.

  3. Install the app

    Download the desktop app on each computer you want in sync.

  4. Connect

    Pick the server it finds on your network, or pair with a code like NULL-7K2Q-9F.

Verify your download

Every release ships a SHA256SUMS.txt, and all 5.0.0 hashes are on the Downloads page. Compare the hash of the file you downloaded before running it.

# Windows (PowerShell)
PS> Get-FileHash .\nulldrive_5.0.0_windows_amd64.zip
# 0885f0856f174f0dda3390256955cc3e055f55a6
#   5f06b0c6b4e2c5e9084c2d56
# Linux / macOS
$ sha256sum -c SHA256SUMS.txt --ignore-missing
# nulldrive_5.0.0_linux_arm64.tar.gz: OK
